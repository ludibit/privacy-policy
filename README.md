## Editing and publishing

Edit [privacy-policy.md](privacy-policy.md), the single source for the policy. `index.md` includes it and GitHub Pages renders it with the local layout. Push changes to `main` to publish; Pages uses the repository root. The page needs no external fonts, scripts, analytics or frontend dependencies.

The policy covers **Ideal Timers**. Keep it aligned with the app's actual data practices and update the effective date when those practices change.

When editing the Markdown, also update the policy body in
`ludibit/ludibit.github.io/ideal_timers/privacy-policy/index.html` and its source
copy in Ideal Timers' `website/developer/ideal_timers/privacy-policy/index.html`.
Keep policy wording identical at both public URLs. The shared stylesheet lives
at `https://ludibit.github.io/styles.css`. Use commit author
`ludibit <iamludibit@gmail.com>` for this repository.

App source remains in its existing private repository. This repository contains only policy and website materials. Publishing this page does not complete app release checks, in-app policy linking, production ad configuration or Play Console declarations.
